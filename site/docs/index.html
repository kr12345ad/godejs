Node-shaped.
Engine-deep.

GodeJS runs the Node 24 API surface on JavaScriptCore and Go. This page covers the engine binding, installation on Alpine and Debian, and the HTTP/3 server that Node and Bun do not ship.

01 / install

One POSIX installer, including BusyBox ash.

install.sh uses only POSIX shell syntax, so it runs under Alpine's ash as well as Debian's dash and Bash. The default path installs a release into $HOME/.local/bin. 

curl -fsSL https://kr12345ad.github.io/godejs/install.sh | sh

# Build from source (needs Go, a C compiler, and JSC headers)
curl -fsSL https://kr12345ad.github.io/godejs/install.sh | sh -s -- --source

# Choose a prefix or a release
curl -fsSL https://kr12345ad.github.io/godejs/install.sh | \
  GODE_PREFIX=/usr/local sh
curl -fsSL https://kr12345ad.github.io/godejs/install.sh | \
  GODE_VERSION=v0.1.0 sh

Debian / Ubuntu

sudo apt install libjavascriptcoregtk-4.0-18
# source builds:
sudo apt install libjavascriptcoregtk-4.0-dev golang gcc

Alpine / ash

sudo apk add webkit2gtk-4.0
# source builds:
sudo apk add webkit2gtk-4.0-dev go gcc musl-dev

The released binary dynamically links libjavascriptcoregtk-4.0.so.18. If the runtime library is missing, the installer prints the distribution-specific package for you.

02 / engine

JavaScriptCore, not V8.

The engine is embedded through the C API in internal/js. There is no V8 shim, no goja fallback, and no JavaScript bootstrap layer pretending to be an engine.

Handles are NaN-boxed

Storing a JavaScriptCore value in a Go pointer slot makes the GC abort. Values are kept as tagged uintptrs instead.

The context is thread-affine

cmd/gode pins its goroutine to one OS thread. I/O runs on goroutines; JavaScript stays on the engine thread.

Generational GC is off by default

Large WebAssembly guests corrupt JSC's generational collector while growing memory, so js.New sets JSC_useGenerationalGC=0.

Real CallSites

JSC gives a formatted stack string. GodeJS keeps the default format and activates structured CallSites only when Error.prepareStackTrace is set.

Source layout

  • internal/js/jsc.go — contexts, evaluation, promises, errors.
  • internal/js/value.go — objects, arrays, typed arrays, property access.
  • internal/js/callback.go — the C callback bridge into Go.
  • internal/env/stack.go — the V8-style CallSite layer.
03 / transport

A native HTTP/3 server.

Node and Bun ship HTTP/1.1 and HTTP/2 servers. GodeJS adds QUIC/HTTP/3 through Go's quic-go, reusing the same IncomingMessage and ServerResponse classes. 

const fs = require('node:fs');
const http3 = require('gode:http3');

const server = http3.createServer({
  key: fs.readFileSync('key.pem'),
  cert: fs.readFileSync('cert.pem'),
}, (req, res) => {
  res.setHeader('content-type', 'application/json');
  res.end(JSON.stringify({ ok: true, url: req.url }));
});

server.listen(4433, '0.0.0.0', () => {
  console.log('HTTP/3 on', server.address());
});

Generate a local certificate

openssl req -x509 -newkey rsa:2048 -nodes -days 1 \
  -keyout key.pem -out cert.pem -subj '/CN=localhost' \
  -addext 'subjectAltName=DNS:localhost,IP:127.0.0.1'

Same handler surface

Streaming write(), setHeader(), statusCode, req.url, body events, and server.close() behave like node:http.

No fallback built in

The module is HTTP/3 only. Run an HTTP/1.1 or HTTP/2 listener alongside it when clients need a fallback, and open the UDP port.

04 / beyond node

Things the built-in runtimes cannot do.

  • HTTP/3 in the standard library. Node and Bun need a native addon or an external proxy to terminate QUIC.
  • Swap the engine without swapping the runtime. The same Node-shaped modules run on JavaScriptCore instead of V8.
  • Go concurrency underneath. I/O and child processes are goroutines; worker threads get independent JSC isolates.

GodeJS targets Node 24.22.2 compatibility, but parity is measured test by test — see the homepage progress snapshot.
