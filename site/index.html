Built like a runtime.

JavaScriptCore provides the engine; Go provides the runtime, I/O, and platform glue.

01

Node 24 API surface

Core modules, CommonJS, ESM, streams, buffers, fs, net, crypto, zlib, and more.

02

Go concurrency

Goroutines drive I/O and child processes. Worker threads get independent JavaScriptCore isolates.

03

Real REPL

Run gode with no arguments for a Node-style prompt, _, and .exit.

04

Node-style CLI

gode app.js, gode -e, gode -p, preloads, and script arguments.

05

No V8

JavaScriptCore keeps the runtime small and makes the engine boundary explicit.

06

Measured, not guessed

Official Node tests run against the real executable, with stdout and error compatibility checked.

Quick start.

Install a release, then use it like Node.

Use it

$ gode
Welcome to GodeJS v24.22.2 (JavaScriptCore)
> 1 + 1
2
> .exit

$ gode app.js
$ gode -e "console.log(process.version)"

On first run, ensure JavaScriptCore is installed and gode is on your PATH.

Build from source

$ sudo apt install libjavascriptcoregtk-4.0-dev
$ go build -o gode ./cmd/gode
$ ./gode

Requires Go 1.26+ and the JavaScriptCore GTK 4.0 development library.
